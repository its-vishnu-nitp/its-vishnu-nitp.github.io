04 Research

🛡️

RL Agent for Adversarial Robustness of ML Malware Detectors

Dual-degree research project · NIT Patna · Supervisor: Dr. Jyoti Prakash Singh

In progress · design phase

An RL agent learns functionality-preserving PE transformation sequences that flip a static ML malware detector from malicious → benign — measuring how robust the detector really is. Success is measured by ERFP (evasion rate with functionality preservation).

  1. Oraclefrozen EMBER-style GBDT as the score oracle
  2. Policyshared RL policy, ~10 actions / episode
  3. Budget~50 detector queries / sample
  4. Safetyisolated lab sandbox validation
  5. TransferMalConv reserved for transfer tests

Workflow: design-first — system designed step by step (scope → dataset/oracle → state representation → action space → …), code only after design sign-off.
